# Little Plates

A small UK family food idea finder. Browse 16 simple dishes, snacks, desserts and drinks inspired mainly by the Middle East, South Asia, East Asia and Africa, with ideas from South America and the Pacific. Choose a category and a parent-friendly goal. Each idea has an illustrative photo, ingredients and short steps. The supermarket selector changes the shopping-list heading; it does not check live stock or prices.

Live website: https://ali1989ec-ship-it.github.io/little-plates/

## Run locally

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Check

Run `node --check script.js`. Try each filter, open a recipe, and test the page on a narrow screen.

## Notes

This beta uses a curated, static recipe list. It has no account, data storage, live supermarket catalogue, prices, or personalised nutrition advice. The recipes use plant, egg and dairy ingredients, with no pork, meat, alcohol, wine, gelatin or alcohol-based flavouring specified. They are not a certification of packaged products: check labels, allergens and preparation choices before serving. Adapt portions and textures to the child.
