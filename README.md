# Little Plates

A small UK family meal idea finder. Choose breakfast, lunch, dinner or snack and a parent-friendly goal to browse 12 simple ideas. The supermarket selector changes the shopping-list heading; it does not check live stock or prices.

## Run locally

Open `index.html` in a browser, or serve this folder with `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Check

Run `node --check script.js`. Try each filter, open a recipe, and test the page on a narrow screen.

## Notes

This beta uses a curated, static recipe list. It has no account, data storage, live supermarket catalogue, prices, or personalised nutrition advice. Check ingredients for allergies and adapt portions and textures to the child.
